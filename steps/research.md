## research
persona: architect
gate: none

Find out. Read primary sources (official docs, the library's source, changelogs) and, where reading is not enough, try the options in the scratchpad: throwaway code, never the worktree. Write research.md: the question, findings with links or file:line, what was tried and what happened, one recommendation, and what is still unknown.
End the artifact with `## Open questions`: one numbered item per question, written `Short label: full question, with options and a default if there is a choice (Default: X)`. The label is what the Next block shows. Put statements and assumptions elsewhere in the artifact. Write "none" if there are no questions.
