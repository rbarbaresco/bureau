# Security

Bureau's gate hooks are the part that keeps an agent from editing code before you approve. If you find a way around them, for example an edit allowed without `/approve`, a forged approval, or a bypass of card ownership, please report it privately: open the repo's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/rbarbaresco/bureau/security/advisories/new)). Do not open a public issue.

Bureau is maintained by one person and is early work, so there is no response-time promise. The limits that are already known are listed in [What these do not cover](README.md#what-is-enforced-and-what-is-not); those are not reports.
